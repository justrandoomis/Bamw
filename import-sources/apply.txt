# The authorisation for a single import write. Empty on purpose.
#
# This file is read by `scripts/catalogue-import-runner.mjs`. The first line
# that is not blank and not a comment is a token; it is claimed in the
# `console_runs` table before a single row is written, with the same
# `INSERT ... ON CONFLICT DO NOTHING RETURNING id` the D1 console uses. So it
# authorises exactly one run and then spends itself — a later push finds the
# token already recorded and stays a dry run.
#
# As committed, there is no token here, so the import cannot write. That is
# deliberate. GitHub only accepts a `workflow_dispatch` for a workflow already
# on the default branch, so until `catalogue-import.yml` merges the only trigger
# is a push, and a push that could write would re-import the catalogue every
# time this script is edited afterwards.
#
# ## To authorise a run
#
# Uncomment the line at the bottom, or write a new token, and commit. The commit
# is the record of who asked for it and what they were told it would do.
