#   Continue to .N for as many entries as genuinely exist — 1, 10, 30, more.

# =========================================
# كل حقل يظهر في صفحة تفاصيل اللعبة يجب البحث عنه وتعبئته إن وُجدت معلومة حقيقية.

# Every field shown on the game details page must be researched and filled
# whenever factual information exists. Do not leave one blank merely
# because it needs deeper research — and never invent facts.
#
# إذا كانت المعلومة غير موجودة فعلاً أو غير منطبقة، اكتب جملة واضحة للقارئ:
#   "لم يُعلن عن أي محتوى إضافي مستقل."
#   "لا يدعم اللعب اللاسلكي المحلي."
# When something genuinely does not exist or does not apply, write a short
# human sentence in USER-FACING TEXT fields:
#   "No standalone DLC has been announced."
#   "No official soundtrack release has been announced."
#   "Local wireless multiplayer is not supported."
# Do NOT write N/A, Unknown, -, or "Not available" where a clear sentence
# belongs. A section with no content is hidden on the page, so an empty
# field is silence — not an explanation.
# =========================================

# BOOLEAN RULE:
# Boolean fields accept only:
#   true
#   false
#   blank if unknown
#
# Never write: Not Published / Unknown / N/A / Yes / No / Not Supported

# device_performance.X.handheld.notes / .tv.notes / .performance_notes.
#

#   true  = resolution is dynamic
#   false = resolution is fixed
#   blank = unknown
# The measured values belong in resolution / rendering_resolution /
# output_resolution — never in resolution_dynamic.
#
# Player counts live in players_count / players / player_count, never in a
# multiplayer_* flag.
# =========================================

# لكل حقل صورة دور مختلف. لا تضع نفس الرابط في أكثر من دور.
# Each image field has a DIFFERENT job. Do not put the same URL in two roles.
#
# ── front_cover_image — Front Box Cover ─────────────────────
#   صورة عمودية نظيفة عالية الدقة لعلبة اللعبة من الأمام مباشرة.
#   بدون هوامش/خلفية بيضاء حول العلبة. العلبة نفسها يجب أن تبقى كاملة.
#   A clean, high-resolution, VERTICAL photo of the retail box seen
#   straight from the front. Crop away the outer white canvas, never
#   the box itself — keep its edges, plastic border, ratings and logos.
#   Used by: Latest Nintendo Releases, /nintendo_games, and as the
#   static image shown in place of the 3D model when none is possible.
#
# ── nintendo_card_image — Square Card Image ─────────────────
#   فن مربّع (أو شبه مربّع) مُعدّ لنافذة الصورة داخل بطاقة الخرطوشة.
#   ليست صورة علبة. يجب أن تكون مقروءة بحجم صغير ومتمركزة بصرياً.
#   SQUARE / near-square key art prepared for the artwork window inside
#   the cartridge-style card. This is NOT a retail box cover. It must
#   read well at small size. The card supplies its own frame.
#   Used by: the homepage "ألعاب نينتندو سويتش" strip.
#
# ── cover_texture_url — 3D Texture Source (OPTIONAL) ───────
#   الغلاف الكامل بدقة عالية: Back Cover + Spine + Front Cover في صورة واحدة.
#   إن لم يتوفر غلاف كامل حقيقي: اترك الحقل فارغاً.
#   The complete printed wrap in ONE image, laid out left to right as
